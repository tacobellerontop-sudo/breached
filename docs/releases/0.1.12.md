What's new in 0.1.12: Breached keeps itself up to date, and three new mods.

- **Automatic engine updates.** When Mozilla releases a new Firefox, Breached makes a new release on it by itself after its tests pass, so Firefox's security fixes reach you through settings > Updates without waiting for anyone.
- **Picture-in-picture mod**: a video plays in a small window that stays on top. Point at a video for the button, or type `:pip` (Ctrl+Shift+]).
- **Translate pages mod**: Firefox's private translation, done on your computer. Breached asks when a page is in another language, or type `:translate` (`:translate off` for the original).
- **Custom CSS per site mod**: your own style rules for a website. `:css` edits them in the command bar.
- The PDF viewer no longer logs an error about its find bar.

Get the mods from the mods site (`:mods get`). Installed copies update from settings > Updates (or `:update`).
