What's new in 0.1.14: extensions open as pop-ups.

- **Extension windows open on top.** When an extension opens a window or one of its own pages (like Bitwarden's passkey or sign-in window, or an options page), it now opens as a small window on top of Breached instead of a tab. The page you were on stays where it was.
- **Closing an extension's window only closes that window.** Before, an extension closing its window could close Breached's.

Web pages an extension opens still open as tabs. Installed copies update from settings > Updates (or `:update`).
