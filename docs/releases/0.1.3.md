What's new in 0.1.3:

- **Esc leaves a page's text box.** Press Esc in a search box, form field or editor and the keyboard lets go of it, so `:` opens the command bar straight away, without clicking somewhere else first. The page still sees the Esc too (to close its own pop-ups).

Installed copies can update from settings > Updates (or `:update`).
