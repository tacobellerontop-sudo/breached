What's new in 0.1.4: faster loading, with memory use kept the same or lower.

- **Connects before you arrive.** While you type an address or search in the command bar or the home page box, point at a home page tile, or press the mouse on a link to another site, Breached already opens the connection to that site, so the page starts loading sooner. Sites' own "connect early" hints work again too.
- **Network tweaks that cost nothing:** no holding back a page's requests, a few more connections to busy sites, and DNS answers and secure-connection sessions kept longer so revisits skip those steps. Loading pages are painted a little sooner.
- **Less in the box and in the background:** Firefox's emoji font is gone (Windows' own is used), along with a test media plugin and a couple of background downloads nothing in Breached used. The security-list worker lets go of its memory 5 seconds after startup work instead of 30.
- **Unloading idle tabs now returns their memory** to Windows straight away.

Installed copies can update from settings > Updates (or `:update`).
