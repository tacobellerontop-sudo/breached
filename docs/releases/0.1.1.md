What's new in 0.1.1:

- Settings is split into pages (Appearance, Browsing, Privacy, Downloads, Extensions and mods, Updates, About) instead of one long list.
- Updates: settings > Updates checks GitHub for a newer Breached. An installed copy downloads and installs it, then starts again; a portable copy opens the release page. Breached also checks once a day and tells you in the message bar (turn that off in settings). `:update` opens it.
- Bitwarden mod: `:bw.exe` shows the matching logins as rows you pick with the arrow keys and Enter, or by typing to filter, instead of rerunning it with a number.
- New default colours: pastel silver and orange.

Updating from 0.1.0: 0.1.0 can't update itself, so run the new installer once over it. Your settings and profile stay.
