What's new in 0.1.8: Netflix, Disney+ and other streaming sites play.

- **Breached now runs on Mozilla's own Firefox engine**, kept exactly as Mozilla signs it. Streaming sites only play protected video in browsers whose engine Google has certified, and Mozilla's is. Until now Breached used its own build of the same engine, which sites turned away.
- breached.exe is now a small launcher that starts the engine (firefox.exe in Breached's folder) with Breached's interface. Your profile, settings and mods stay where they were.
- The installer now clears out the old version's program files when it updates, so nothing from the old engine is left behind.
- For streaming sites, install the Protected video mod (Breached offers it the first time a site needs it).

Installed copies can update from settings > Updates (or `:update`).
