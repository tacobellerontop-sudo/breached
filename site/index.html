    Questions

    Is it free?

    Yes. No account, no subscription, no ads. The code is on GitHub.

    Why does Windows warn me when I install it?

    Breached isn't code-signed yet, so SmartScreen doesn't know the publisher. Choose More info, then Run anyway.

    Is it Firefox?

    It runs on Mozilla's own signed Firefox engine, so pages work as they do in Firefox. Everything around the page is Breached's own.

    Do Netflix and Spotify play?

    Yes, with the Protected video mod. Breached offers it the first time a site needs it.

    How do I update?

    Type :update or open settings > Updates. Breached also checks once a day.
